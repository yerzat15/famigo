## 3. Как пришли к идее (история решений)

1. Сначала думали, что кейс свободный и локальный → идея «Чем заняться в Астане сегодня» (лента событий с фильтрами по бюджету, аудитории и т.д.). Был написан черновой бэкенд на FastAPI (`astana-events`) — **больше не используется**.
2. Пользователь выбрал варианты стека: FastAPI (1A), Supabase (2B), данные — парсинг + форма организаторов (3BD), ИИ подбирает и объясняет (4B), Render + Vercel (6A).
3. Erzat узнал, что аудитория — США 25–45. Проверили видео-презентацию кейса и подтвердили. Вывод: «события Астаны для студентов» не проходит (не тот пользователь; лента событий бесплатна у Eventbrite/Meetup/Google → слабо по «что продаём», «новизна», «бизнес»).
4. Предложены направления для US 25–45 в треке Entertainment: A) планировщик выходных для работающих родителей, B) свидания для пар, C) для переехавших в новый город, D) туризм. **Выбран A.**
5. Состав плана: A) только события, B) события + бесплатные места, C) события + места + еда. **Выбран C** («кто не рискует, тот не пьёт шампанское»).
6. ИИ: денег на API нет; подписка Claude не даёт доступа к API (подтверждено в support.claude.com) → **Google Gemini, бесплатный уровень**, модель Flash-Lite (у неё самые большие бесплатные лимиты).
7. Вид плана: A) список карточек, B) карточки + карта, C) таймлайн. **Выбран C (таймлайн).** Карта — «если останется время».
8. Команда стала соло → фронт: A) FastAPI + HTML-шаблоны + Tailwind CDN + vanilla JS, B) отдельный React на Vercel, C) Next.js. **Выбран A.** Supabase отложен — SQLite.
9. Overpass (публичный OpenStreetMap API) оказался перегружен: `502 ... server is currently at capacity`, второй сервер — ReadTimeout → перешли на **Geoapify Places** (те же данные OSM, стабильно; ключ выдаётся сразу), Overpass оставлен запасным.
10. Ticketmaster: зарегистрировались, письмо «pending admin approval» → события пока не работают; продукт функционирует без них.
11. Название: рабочее «Weekendly» отклонено — существует похожее приложение **Weekdly** (планирование выходных). Предлагались Kinday, Saturday Sorted, Outwith, Famigo. **Выбрано Famigo** (family + amigo/go). Проверка домена/App Store/USPTO на занятость **не делалась**.

## 4. Продукт

### Пользователь (персона для питча)
Работающий родитель в США, ~30–42 лет, 1–3 ребёнка ~2–12 лет. Всю неделю работа; в субботу утром семья не знает, чем заняться. Боль: выходные уходят на «экран + торговый центр» и чувство вины; составление плана — поиск в Google, группах, проверка погоды, цен, расстояний, возраста детей.

### Как работает
1. Ввод (~30 сек): город или ZIP, дата, бюджет, взрослые, возраст детей, vibe (anything/outdoors/indoors), макс. расстояние, заметка («my son loves dinosaurs»).
2. Бэкенд собирает реальные данные: погода (Open-Meteo), места и еда (Geoapify/OSM), события (Ticketmaster, когда будет ключ).
3. Shortlist: фильтр по расстоянию, бюджету, vibe, погоде (в дождь — помещения первыми), исключение событий 18+/21+, разнообразие категорий.
4. Gemini выбирает 3–5 пунктов с 09:00 до 19:00, ровно один приём пищи, объясняет «why» под конкретную семью.
5. Бэкенд валидирует, считает стоимость, принудительно держит бюджет.
6. Таймлайн, кнопки Directions (Google Maps по координатам), Tickets (для событий), Swap (замена пункта без ИИ), Share (ссылка `/p/<id>`).

### Бизнес-модель (как в продукте и README)
- **Бесплатно:** 3 плана в месяц, без регистрации (счётчик в localStorage браузера).
- **Famigo Family — $6.99/мес:** безлимитные планы, готовый план каждую пятницу в 18:00, планировщики на школьные каникулы. В paywall — «Start 7-day free trial» (если задан `STRIPE_PAYMENT_LINK`).
- Удержание: еженедельный ритуал «план на выходные в пятницу».

## 5. Ход разработки и баги, которые уже решены

| Проблема | Решение |
|---|---|
| `python` не найден в Windows | Установлен Python с python.org с галочкой «Add to PATH» |
| `Activate.ps1` — scripts disabled | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| Архив распаковался во вложенную папку | Работать в папке, где лежит `requirements.txt` |
| `uvicorn[standard]` → сборка `pyyaml` требует C++ на Python 3.15 | `requirements.txt` → просто `uvicorn` |
| `/health` → `gemini:false` | Ключи были вписаны в `.env.example` вместо `.env` → переименовали, шаблон восстановлен без ключей |
| «We couldn't find activities in that area» | Overpass перегружен → Geoapify как основной источник; пустые результаты больше не кешируются |
| Gemini превысил бюджет ($128 при $100) | `enforce_budget()` после ответа ИИ + тест |
| Двойные названия мест через «;» | Берётся часть до «;» |
| Нельзя удалить `.db` (EBUSY) | Сначала остановить сервер |
| Переименование в Famigo | Проект собран заново в `hacaton\Famigo`, все упоминания Weekendly заменены; venv пересоздан |
| На Render Python по умолчанию мог быть новее | Добавлен `.python-version` = 3.13 |

Проверка в продакшене (`/debug`, Austin TX): 199 мест, 295 точек еды, геокодинг и погода работают; `/health` → `gemini: true, ticketmaster: false`. План в локальной версии собирался ИИ («Plan composed by AI»), объяснения учитывали морось и возраст детей 4 и 8.

## 6. Исследование для питча (найдено веб-поиском, с источниками)

**Рынок / пользователь**
- В 2025 году **32,9 млн семей** в США имели детей до 18 лет (почти две пятых всех семей); хотя бы один родитель работал в 91,6% таких семей. — BLS, Employment Characteristics of Families 2025: https://www.bls.gov/news.release/famee.htm
- Доля семей со своими детьми до 18 лет снизилась с 54% (1975) до 39% (2025). — Census, Families and Living Arrangements (дек. 2025).

**Боль**
- Родители тратят **30,4 часа в неделю** на планирование и координацию семейных задач и расписаний; 61% говорят, что нагрузка от расписаний сократила время с партнёром. — Skylight Mental Load Report, The Harris Poll, 2 005 родителей, май 2024: https://myskylight.com/mental-load-report/
- 53% мам находят сложным планировать семейные активности на летних выходных; 42% — придумывать новые идеи помимо того, что делают каждый год; 46% — найти занятия и на улице, и в помещении. — OnePoll для Mother's Cookies, 2 000 мам детей 5–12 лет (через StudyFinds).
- 29% родителей говорят, что ограничения бюджета мешают семье заниматься желаемыми развлечениями. — Mintel, family leisure.

**Деньги**
- Родители детей 3–16 лет тратят в среднем **$466/мес** (медиана $250) на семейные покупки и впечатления сверх необходимого. — ICSC «Family-Focused Retail», июнь 2026, 1 004 взрослых.
- 61% родителей чувствуют давление тратить больше на детей, чтобы не отставать от других семей; 70% планируют сократить расходы на детей, больше всего — на игрушки и развлечения (27%). — LendingTree.

**Конкуренты / похожие**
- **Cube** (pre-launch, cube-777.pages.dev): планировщик выходных для родителей в США с детьми 3–12; каждую пятницу утром присылает 3 варианта на субботу, учится на реальных посещениях. Прямой конкурент и подтверждение боли.
- **Weekdly** — приложение для планирования выходных (причина отказа от названия Weekendly).
- **FamDay** — общий семейный календарь, $8.99/мес (ориентир цены подписки в нише).
- Woend / Weekend Planner, Cubbily, Skylight — календари/организаторы, а не подбор реальных мест под бюджет и погоду.
- Также упоминались: Google, Eventbrite, Meetup (бесплатные ленты событий).

**Расчёт для слайда (это ДОПУЩЕНИЯ, не данные — так и подавать)**
- 32,9 млн семей × $6.99 × 12 ≈ $2,76 млрд/год — потолок рынка подписки.
- ~1,2 млн платящих семей (≈3,6%) × $83.88/год ≈ $100M ARR.
- Ранее в чате фигурировало «~30 млн семей, 1% × $6.99 ≈ $25M ARR» — заменено цифрой BLS (32,9 млн).
- LTV/CAC конкретными данными не подтверждены; идея: вирусный канал через «Share with partner» и родительские сообщества.

**Лимиты API (для понимания рисков)**
- Ticketmaster Discovery API: по умолчанию 5 000 запросов/день, 5 запросов/сек.
- Overpass: ~10 000 запросов/день на основном сервере, без параллельных скриптов; на практике был перегружен.
- Gemini free tier: Google больше не публикует точные лимиты; по сторонним данным Flash ≈ 20 запросов/день, Flash-Lite ≈ 500. Отсюда: кеш ИИ-ответов (6 ч), один запрос на план, fallback без ИИ.
- Geoapify: бесплатный тариф (точный лимит не проверялся); места кешируются на 7 дней.
